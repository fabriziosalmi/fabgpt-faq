# Come vedo quanto spazio disco resta?

df -h

Guarda Use% e il mountpoint giusto: il 100% su / spegne i servizi in modi creativi.

# Spazio libero ma "no space left on device": perché?

df -i

Con IUse% al 100% gli inode sono finiti (milioni di file piccoli): lo spazio c'è, i "posti" no.

# Come monto un disco al volo?

# Come monto un disco in automatico al boot (fstab)?

blkid /dev/sdb1     # prendi l'UUID
# /etc/fstab:
UUID=xxxx-xxxx  /mnt/dati  ext4  defaults,nofail  0 2
mount -a            # test SENZA riavviare

Sempre per UUID (i nomi /dev/sdX ballano) e con nofail: un disco assente non deve bloccare il boot.

# Come controllo e riparo un filesystem (fsck)?

umount /dev/sdb1
fsck -f /dev/sdb1

MAI su un filesystem montato in scrittura: peggiora le cose. Per la root: da initramfs o live USB.

# Come controllo la salute SMART di un disco?

smartctl -a /dev/sda | grep -Ei 'reallocated|pending|health'

Reallocated e Current_Pending_Sector sopra lo zero = pianifica la sostituzione, non sperarci.

# Come misuro la velocità di un disco?

# lettura sequenziale rapida:
hdparm -t /dev/sda
# test serio (random 4k):
fio --name=t --filename=/mnt/dati/t --size=1G --rw=randread --bs=4k --numjobs=4 --runtime=30 --group_reporting

dd misura solo il sequenziale con cache di mezzo: per i numeri veri serve fio.

# Come creo uno swapfile?

fallocate -l 2G /swapfile && chmod 600 /swapfile
mkswap /swapfile && swapon /swapfile
# persistente: /swapfile none swap sw 0 0  in /etc/fstab

Su btrfs e ZFS lo swapfile richiede accorgimenti (o va evitato): lì meglio una partizione o zram.

# Come vedo quanta swap sto usando (e chi la usa)?

swapon --show && free -h
# per processo: smem -s swap -r | head

Swap usata con RAM libera = pagine fredde parcheggiate, non un problema; swap che CRESCE sotto pressione sì.

# Come controllo un RAID mdadm (e sostituisco un disco)?

cat /proc/mdstat
mdadm --detail /dev/md0
# sostituzione:
mdadm --manage /dev/md0 --fail /dev/sdb1 --remove /dev/sdb1
mdadm --manage /dev/md0 --add /dev/sdc1

Dopo l'add parte il rebuild (progresso in mdstat): è il momento più fragile dell'array – backup prima.

# Come controllo un pool ZFS (e lancio uno scrub)?

zpool status -v
zpool scrub tank

Lo scrub mensile è il momento in cui i checksum fruttano: errori CKSUM su un disco = indiziato numero uno.

# Come creo (e ripristino) uno snapshot ZFS?

zfs snapshot tank/dati@pre-upgrade
zfs rollback tank/dati@pre-upgrade   # distrugge cio' che e' successo dopo!

Il rollback butta tutto ciò che è successo dopo lo snapshot; per un singolo file: .zfs/snapshot/ in sola lettura.
