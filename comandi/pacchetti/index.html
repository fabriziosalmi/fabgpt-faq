# Come aggiorno tutti i pacchetti?

apt update && apt upgrade        # Debian/Ubuntu
dnf upgrade                      # RHEL/Fedora

apt update scarica solo gli INDICI: senza l'upgrade dopo, non hai aggiornato nulla.

# Come installo o rimuovo un pacchetto?

apt install nginx
apt remove nginx      # tiene le config
apt purge nginx       # via anche le config

remove vs purge: se reinstallerai, remove; se vuoi ripartire pulito, purge.

# Come pulisco dipendenze orfane e cache dei pacchetti?

apt autoremove --purge
apt clean

Sicuro per definizione: rimuove solo ciò che nessun pacchetto installato richiede più.

# Quale pacchetto fornisce un certo file o comando?

dnf provides '*/bin/dig'          # RHEL/Fedora
apt-file search bin/dig           # Debian (apt install apt-file; apt-file update)

Il riflesso giusto per ogni command not found: si cerca il file, non si tira a indovinare il nome del pacchetto.

# Come blocco l'aggiornamento di un singolo pacchetto?

apt-mark hold nginx        # sblocco: apt-mark unhold
dnf versionlock add nginx  # (plugin versionlock)

Un hold è debito tecnico con la data di scadenza: annota PERCHÉ l'hai messo, o resterà lì per sempre.

# Come vedo i pacchetti installati (e cerco tra loro)?

apt list --installed 2>/dev/null | grep nginx
dnf list installed | grep nginx

Per sapere se un pacchetto c'è e in che versione; la storia di chi ha installato cosa sta in /var/log/apt/history.log.

# apt ha dipendenze rotte: come sistemo?

apt --fix-broken install
dpkg --configure -a      # se un'installazione si era interrotta

Quasi sempre basta questa coppia; se il pasticcio nasce da un repo di terze parti, il problema è il repo.

# Come aggiungo un repository di terze parti nel modo giusto?

curl -fsSL https://esempio.com/key.gpg | gpg --dearmor -o /usr/share/keyrings/esempio.gpg
echo 'deb [signed-by=/usr/share/keyrings/esempio.gpg] https://repo.esempio.com stable main' > /etc/apt/sources.list.d/esempio.list
apt update

signed-by lega la chiave al SOLO repo che firma: il vecchio apt-key autorizzava quella chiave per tutto.
