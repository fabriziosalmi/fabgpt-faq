# Come verifico la firma crittografica dell'ultimo commit Git?

git log -1 --show-signature

Mostra lo stato di convalida della chiave crittografica (GPG o SSH) che ha firmato l'ultimo commit.

# Come scansiono i secrets nei file in staging prima del commit?

gitleaks protect --staged --verbose

Blocca chiavi API e token in staging prima che vengano scritti nella cronologia git locale.

# Come cifro un file di secrets con SOPS e age?

sops --encrypt --age <age-public-key> secrets.enc.yaml > secrets.enc.yaml

Cifra selettivamente i valori mantenendo in chiaro le chiavi strutturate per diff e merge review puliti.

# Come verifico la firma di un'immagine container OCI con cosign?

cosign verify --key cosign.pub <registry>/<immagine>:<tag>

Convalida il payload della firma OCI e i claim Rekor attestando l'integrita della build.
