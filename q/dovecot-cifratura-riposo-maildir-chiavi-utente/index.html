Come si abilita e gestisce la cifratura a riposo delle caselle di posta IMAP (es. maildir encryption in Dovecot con chiavi univoche)?

Se un server di posta viene compromesso o i dischi vengono esfiltrati fisicamente, i messaggi memorizzati in formato Maildir/mbox possono essere letti in chiaro dagli intrusi. Dovecot integra il plugin nativo mail_crypt per la cifratura a riposo a livello di singola casella:

1. Architettura a Doppia Chiave: ogni utente possiede una coppia di chiavi asimmetriche (pubblica per cifrare all'arrivo dei messaggi da Postfix, privata per decifrare durante la sessione IMAP dell'utente autenticato).
2. Attivazione Plugin in /etc/dovecot/conf.d/90-mail-crypt.conf:
mail_plugins = $mail_plugins mail_crypt
plugin {
mail_crypt_global_private_key = ...
mail_crypt_save_version = 2
}
3. Vantaggio Operativo: l'amministratore di sistema con accesso root al filesystem vede solo payload cifrati incomprensibili, preservando la riservatezza delle comunicazioni aziendali.
