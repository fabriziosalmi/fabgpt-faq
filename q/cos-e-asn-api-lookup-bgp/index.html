Cos'è asn-api e come si interrogano Autonomous System e rotte BGP?

Strumenti e app ⏱️ 2 min lettura ✓ Runbook verificato

asn-api è un microservizio FastAPI ad altissime prestazioni per la risoluzione rapida e a basso overhead di indirizzi IP in Autonomous System Number (ASN), prefissi BGP, Country Code e informazioni sull'organizzazione proprietaria.

Caratteristiche tecniche:
- Lookup ultra-veloce in-memory: carica i database IP-to-ASN (MaxMind, RouteViews, Team Cymru) in strutture dati ad albero binario / radix trie in memoria RAM con tempi di risposta < 1ms.
- Interfaccia REST & JSON: endpoint semplici per query singole (/asn/1.1.1.1) o bulk query per SIEM, script di incident response e pipeline di sicurezza.
- Container compatto: immagine Docker basata su Alpine Linux o Distroless, con consumi di risorse minimi (< 50MB RAM).

Avvio immediato con Docker:

BASH
# Avvio del container asn-api
docker run -d --name asn-api -p 8000:8000 ghcr.io/fabriziosalmi/asn-api:latest

# Test di query per un indirizzo IP
curl http://localhost:8000/asn/8.8.8.8

Indispensabile per arricchire log di sicurezza, WAF e firewall con metadati geografici e di routing BGP in tempo reale.
