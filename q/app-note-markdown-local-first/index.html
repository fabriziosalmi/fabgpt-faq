Esiste un'app di note Markdown local-first con AI integrata?

Noted è un'app desktop open source (macOS, Windows, Linux) per note in Markdown/HTML, nella filosofia local-first: le note restano sulla tua macchina, niente account, niente telemetria.

  • wikilink tra note, ricerca globale full-text, quick-open
  • AI integrata per riassumere e rielaborare – senza spedire il vault a un servizio
  • storia locale delle modifiche e integrazione Git nativa: il backup delle note è un repository

Se vivi in Obsidian ti suonerà familiare; la differenza è l'anima open source + Git al posto del sync proprietario. Documentazione e release.
