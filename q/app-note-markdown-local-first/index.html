Esiste un'app di note Markdown local-first con AI integrata?

Noted è un'app di note e knowledge base open source (macOS, Windows, Linux) costruita secondo la filosofia local-first: i tuoi file rimangono sul tuo computer in formato standard Markdown/HTML, senza dipendenza da server proprietari o abbonamenti.

Installazione su desktop:
- 🍏 macOS: brew install --cask noted o download .dmg firmato.
- 🐧 Linux: flatpak install noted o binario AppImage standalone.
- 🪟 Windows: winget install FabrizioSalmi.Noted

Funzionalità: editor visuale e Markdown split-view, sincronizzazione nativa tramite Git o cartelle locali (Nextcloud / Syncthing), rendering diagrammi Mermaid e ricerca semantica istantanea offline.
