Come si monitora un sito web usando solo GitHub Actions?

Con websites-monitor: monitoraggio di siti web fatto interamente con GitHub Actions, senza server da mantenere. Controlla:

  • scadenza di domini e certificati
  • security header e configurazione TLS
  • performance
  • privacy e SEO

Il report vive nel repository stesso: costo zero, storia versionata in git, e nessuna dashboard esterna da pagare.
