Cos'è Secure Proxy Manager (SPM) e come funziona come Secure Web Gateway?

Secure Proxy Manager (SPM) (github.com/fabriziosalmi/secure-proxy-manager) è un Secure Web Gateway (SWG) self-hosted open source: un punto di uscita controllato per reti home, lab o uffici che impedisce a client e server di contattare destinazioni malevole o non autorizzate.

Architettura a microservizi (Docker Compose):
- Squid forward proxy (porta 3128): gestisce l'egress e invia il traffico HTTP/S al WAF via protocollo ICAP.
- WAF in Go: ispeziona richieste e risposte su 21 categorie di minaccia (testate con approccio adversarial FN=0).
- DNS Sinkhole (dnsmasq): intercetta e blocca domini di malware, tracker e C2 a livello DNS.
- Management UI: dashboard moderna in React 19 + Vite con backend Go ultra-leggero (~20 MB RAM) e sidecar Tailscale opzionale per l'accesso remoto.

Quick Start:

git clone https://github.com/fabriziosalmi/secure-proxy-manager.git
cd secure-proxy-manager
docker compose up -d

Accesso alla dashboard di gestione su https://localhost:8443.
