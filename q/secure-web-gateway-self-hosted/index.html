Cos'è un Secure Web Gateway (SWG) e come si usa Secure Proxy Manager?

Cybersecurity ⏱️ 1 min lettura ✓ Runbook verificato

Secure Proxy Manager (SPM) (github.com/fabriziosalmi/secure-proxy-manager) è la controparte self-hosted e open source di Cloudflare Gateway e Zscaler: un Secure Web Gateway (SWG) che fa da unico punto di uscita controllato per la rete locale, bloccando malware, C2 e connessioni non autorizzate senza che i dati lascino la tua infrastruttura.

Architettura a microservizi (Docker Compose):
- Squid forward proxy (porta 3128): controlla l'egress con allowlist default-deny e invia il traffico al WAF via protocollo ICAP.
- WAF in Go: ispeziona richieste e risposte su 21 categorie di minaccia (testate con approccio adversarial FN=0).
- DNS Sinkhole (dnsmasq): intercetta e neutralizza domini malevoli a livello di risoluzione DNS.
- Management UI: dashboard moderna in React 19 + Vite con backend Go leggero (~20 MB RAM) e sidecar Tailscale opzionale.

Quick Start:

BASH
git clone https://github.com/fabriziosalmi/secure-proxy-manager.git
cd secure-proxy-manager
docker compose up -d

Dashboard su https://localhost:8443.
