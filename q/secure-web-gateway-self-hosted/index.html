Cos'è un Secure Web Gateway e come se ne self-hosta uno?

Un Secure Web Gateway (SWG) è il punto unico e controllato da cui esce il traffico di una rete: filtra i domini, ispeziona le richieste, blocca malware e pubblicità prima che raggiungano i client. Le versioni cloud (Zscaler, Cloudflare Gateway) funzionano – ma fanno passare tutto il tuo traffico da un datacenter altrui.

secure-proxy-manager è il contraltare self-hosted: un unico stack Docker Compose che combina proxy Squid, WAF custom (ispezione richieste/risposte via ICAP), DNS sinkhole per domini malevoli e pubblicitari, allowlist di egress default-deny, e una web UI moderna con API. Il WAF copre 21 categorie di attacco con un gate di release a zero falsi negativi sui test; le immagini sono firmate cosign. Per una casa, un lab o un piccolo ufficio: nessun traffico lascia la tua rete.
