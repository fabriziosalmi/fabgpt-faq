Come si scopre se i propri dati sono finiti in un data breach?

Per un controllo una tantum esistono servizi come Have I Been Pwned. Ma per un'organizzazione serve monitoraggio continuo, e farlo con un SaaS significa consegnare a terzi la lista di ciò che ti fa più male. NASO è l'alternativa self-hosted: sorveglia corpora di breach, paste site, GitHub pubblico, canali Telegram e servizi onion cercando l'esposizione della tua organizzazione, correla i ritrovamenti in identità e li smista con un LLM che fai girare tu.

L'intero stack – database, indice di ricerca, object store, modello – vive nel tuo Docker Compose: niente esce. È dichiaratamente uno strumento dual-use, per uso difensivo e autorizzato: maneggia dati personali altrui, e il posto più sicuro per farlo è un'infrastruttura che puoi indicare col dito.
