Come si rimuovono i metadati sensibili dai file (MAT2)?

Ogni file porta con sé metadati che raccontano più di quanto pensi: una foto include le coordinate GPS di dove è stata scattata, il modello di fotocamera/telefono, la data; un PDF o un documento Office incorporano autore, software, revisioni, a volte testo cancellato. Pubblicare un file senza ripulirlo è un leak di privacy silenzioso – ci sono stati arresti e de-anonimizzazioni proprio così.

MAT2 (Metadata Anonymisation Toolkit) è lo strumento da riga di comando che li rimuove da decine di formati (immagini, PDF, Office, audio, video): mat2 foto.jpg produce una copia pulita. Ha integrazioni nei file manager (Nautilus) e nel de-Googled mondo.

Le accortezze: alcuni social rimuovono già l'EXIF all'upload (ma non fidarti per default – verifica), la rimozione va fatta prima di condividere (una volta caricato, il metadato potrebbe essere già stato letto), e per i documenti attenzione al contenuto nascosto (testo bianco su bianco, commenti, celle nascoste) che MAT2 non tocca – quello è revisione umana. È l'igiene di base di chi pubblica: un gesto di due secondi che chiude una delle fughe più comuni e sottovalutate.
