Cos'è proxmox-cluster-balancer e come bilancia i nodi di un cluster Proxmox?

Proxmox e self-hosting ⏱️ 2 min lettura ✓ Runbook verificato

proxmox-cluster-balancer è uno strumento di bilanciamento automatico del carico (DRS - Dynamic Resource Scheduling) per cluster Proxmox Virtual Environment (PVE).

Funzionalità e algoritmo:
- Algoritmo Euristico di Distribuzione: monitora costantemente l'utilizzo di CPU, memoria RAM e I/O disco di ciascun nodo del cluster tramite le API Proxmox VE.
- Pianificazione delle Migrazioni (Live Migration): calcola lo squilibrio del carico rispetto a una soglia definita e genera un piano di spostamento ottimale delle macchine virtuali (QEMU/KVM) e container LXC senza interrompere i servizi attivi.
- Modalità Dry-Run e Safe Mode: consente di simulare l'impatto del ribilanciamento prima di applicarlo e di escludere VM critiche o nodi con hardware eterogeneo.

Installazione ed esecuzione:

BASH
# Clone del repository e installazione
git clone https://github.com/fabriziosalmi/proxmox-cluster-balancer.git
cd proxmox-cluster-balancer
pip install -r requirements.txt

# Esecuzione in modalità simulazione (dry-run)
python balancer.py --cluster-conf /etc/pve/corosync.conf --dry-run

Fornisce un'alternativa open source e trasparente ai sistemi di DRS proprietari per massimizzare la resa dei server fisici.
