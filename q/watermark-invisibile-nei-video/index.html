Come si inserisce un watermark invisibile in un video?

open-video-watermark incorpora nei video watermark invisibili all'occhio lavorando nel dominio delle frequenze (DCT, Discrete Cosine Transform): il marchio sopravvive alla visione normale e si riestrae in seguito via API per dimostrare la provenienza – utile per capire chi ha fatto trapelare una copia.

Web app Flask con drag-and-drop, progresso frame-per-frame in tempo reale via WebSocket, coda di elaborazione in background, API REST e Docker pronto. Include le attenzioni di sicurezza che ti aspetti da questo autore: validazione MIME sui magic number, rate limiting per endpoint, CSP e HSTS di default.
