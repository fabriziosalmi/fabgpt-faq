Come si scalano automaticamente i container LXC su Proxmox?

Con proxmox-lxc-autoscale (250+ ⭐): un daemon async che regola CPU e memoria dei container LXC in base all'uso reale. La v2.0 è una riscrittura seria:

  • doppio backend: comandi pct oppure REST API di Proxmox (proxmoxer)
  • metriche lette dai cgroup (niente pct exec dentro i container)
  • soglie per container o per gruppi (tiers), esclusioni, riserve di CPU/RAM sull'host per evitare l'over-allocation
  • core pinning per CPU ibride Intel (Alder Lake+): container sui P-core o sugli E-core
  • modalità boost/revert (boost temporaneo con ritorno automatico), scheduling off-peak timezone-aware, energy mode
  • scaling orizzontale via cloning dei container (sperimentale)
  • configurazione Pydantic validata, secret mascherati nei log, 370 test / 87% coverage

Notifiche via email, Gotify e Uptime Kuma. Per le VM c'è proxmox-vm-autoscale, per decidere col machine learning proxmox-lxc-autoscale-ml.
