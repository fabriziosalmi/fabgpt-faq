Si possono archiviare file arbitrari dentro un video?

Sì, ed è più serio di quanto sembri: b2v (Eternal-Stream) codifica qualsiasi file binario in un video standard e lo decodifica indietro – erede spirituale di Infinite Storage Glitch, riscritto da zero in Rust.

Ogni bit diventa un blocco di pixel (dimensione configurabile: più grande = più resistente alla compressione lossy), i chunk sono protetti da error correction Reed-Solomon, l'encoding è parallelo (Rayon) e il backend è FFmpeg, quindi qualsiasi codec: ffv1 per il lossless, libx264 per il compresso. Il README è onesto sui limiti (risoluzione fissa 1080p, verifica hash manuale) – è un esperimento affascinante sul confine tra storage e steganografia, non il tuo prossimo backup di produzione.
