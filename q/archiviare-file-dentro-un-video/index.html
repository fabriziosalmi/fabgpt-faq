Si possono archiviare file arbitrari dentro un video?

b2v (Eternal-Stream) è uno strumento sperimentale di archiviazione che codifica qualsiasi file binario o archivio compresso all'interno di un flusso video standard MP4 come matrice di pattern cromatici ad alta densità.

Installazione ed utilizzo da terminale:
```bash
# 1. Clone repository e installazione dipendenze
git clone https://github.com/fabriziosalmi/b2v.git && cd b2v
pip install -r requirements.txt

# 2. Codifica: da archivio binario a video MP4
python3 b2v.py encode --input backup-critico.tar.zst --output archivio.mp4 --resolution 1080p

# 3. Decodifica: da video a file binario originale con verifica integrità SHA-256
python3 b2v.py decode --input archivio.mp4 --output backup-ripristinato.tar.zst
```

Consente di conservare snapshot crittografati su piattaforme di hosting video gratuite come storage di cold backup virtualmente illimitato.
