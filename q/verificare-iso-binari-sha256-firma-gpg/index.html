Come si verifica l'integrità crittografica di immagini ISO e binari con SHA-256 e firme GPG?

La verifica crittografica prima dell'installazione previene l'esecuzione di file corrotti o manomessi tramite attacchi man-in-the-middle o mirror compromessi:

1. Verifica Checksum SHA-256: calcola l'hash del file scaricato (sha256sum distro.iso) e confrontalo con il file SHA256SUMS. Questo assicura l'integrità contro errori di download.
2. Verifica della Firma GPG: un attaccante che controlla il mirror potrebbe sostituire sia la ISO che il file degli hash. Per provare l'autenticità dell'autore, importa la chiave pubblica ufficiale (gpg --recv-keys <KEY_ID>) e valida la firma crittografica:
``bash
gpg --verify SHA256SUMS.gpg SHA256SUMS
``
Se l'esito è Good signature, l'integrità e la provenienza del distributore ufficiale sono garantite.
