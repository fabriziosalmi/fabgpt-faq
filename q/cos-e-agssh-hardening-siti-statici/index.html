Cos'è agssh e come si verifica che un sito statico non faccia chiamate esterne?

La gestione sicura degli accessi SSH elimina l'uso di password e chiavi RSA obsolete, adottando chiavi ED25519 o certificati protetti da token hardware FIDO2/YubiKey.

Guida operativa da terminale:

1. Generazione chiave ED25519 standard:
ssh-keygen -t ed25519 -C "admin@homelab" -f ~/.ssh/id_ed25519
2. Generazione chiave protetta da YubiKey hardware (FIDO2):
ssh-keygen -t ed25519-sk -O resident -C "yubikey-fido2"
3. Configurazione client (~/.ssh/config):
``ssh
Host server-prod
HostName 192.168.1.100
User root
Port 2222
IdentityFile ~/.ssh/id_ed25519_sk
IdentitiesOnly yes
`
4. Hardening del server (/etc/ssh/sshd_config):
`
PasswordAuthentication no
PermitRootLogin prohibit-password
PubkeyAuthentication yes
``

Per l'automazione dell'infrastruttura, usa lo strumento agssh.
