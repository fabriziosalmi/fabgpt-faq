Come si migra un sito da Cloudflare a un'infrastruttura self-hosted europea?

flareover è un motore deterministico di migrazione che permette di spostare qualsiasi sito web o applicazione da Cloudflare verso un'infrastruttura open source self-hosted europea senza downtime e senza perdere le funzionalità critiche (TLS, WAF, DNS, Cache, Redirects).

Workflow operativo guidato in 5 fasi da terminale:

# 1. Clone del tool
git clone https://github.com/fabriziosalmi/flareover.git && cd flareover

# 2. Fase 1: Valutazione configurazioni Cloudflare esistenti
./flareover.sh --assess --zone-id "tuo_zone_id" --api-token "tuo_token"

# 3. Fase 2 & 3: Generazione config Nginx/Caddy e regole WAF native
./flareover.sh --generate-caddy --generate-waf

# 4. Fase 4 & 5: Esecuzione switch DNS e verifica con guardrails
./flareover.sh --verify

Garantisce piena sovranità digitale, conformità GDPR e abbattimento della dipendenza da CDN proprietarie esterne.
