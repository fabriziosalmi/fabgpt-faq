Proxmox e self-hosting

Cos'è proxxx, il cockpit da terminale per Proxmox?

proxxx è un cockpit da terminale per Proxmox VE e Proxmox Backup Server: Rust, async, binario statico singolo, nessun installer e nessun agente – parla REST con PVE/PBS e SSH per il resto, invece di chiederti di installare un daemon sul cluster.

Copre pubblici molto diversi:

  • homelab: wizard, TUI veloce, proxxx describe stampa l'intero cluster in un comando
  • SRE/DevOps: exit code tipizzati, JSON deterministico per le pipeline, risk gate pre-flight, operazioni batch, gate di approvazione human-in-the-loop via Telegram
  • integrazione AI: server MCP con registro di 25 tool fissato a compile-time, per collegare Claude o Cursor al cluster
  • compliance UE (NIS2/ISO 27001): audit log append-only in SQLite con catena HMAC-SHA256 e proxxx audit verify, zero telemetria, release firmate sigstore con SBOM CycloneDX

Prima di ogni commit passa un gate a 8 stadi, incluso il test su un cluster reale. Documentazione.
