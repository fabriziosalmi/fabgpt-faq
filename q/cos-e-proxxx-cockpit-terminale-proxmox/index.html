Cos'è proxxx, il cockpit da terminale per Proxmox?

proxxx è un cockpit da terminale ad alte prestazioni per Proxmox VE e Proxmox Backup Server, scritto in Rust con architettura async e distribuito come binario statico singolo senza runtime esterni. Include oltre 25 tool di sistema auditabili a compile-time.

Installazione rapida da terminale:
```bash
# 1. Installazione automatica con rilevamento architettura (x86_64 / arm64)
curl -fsSL https://raw.githubusercontent.com/fabriziosalmi/proxxx/main/install.sh | bash

# 2. Oppure compilazione diretta con Cargo
cargo install --git https://github.com/fabriziosalmi/proxxx

# 3. Avvio interattivo della TUI
proxxx --node pve-node-01 --api-token-file ~/.proxmox-token
```

Permette il monitoraggio real-time di CPU/RAM/IOPS di cluster interi, gestione snapshot ZFS a caldo, migrazione live di VM e controllo storage PBS senza dover aprire l'interfaccia web. Si integra con pegaprox e proxmox-autoscale.
