In che modo l'architettura di SimpleX Chat garantisce la privacy eliminando identificatori utente persistenti?

A differenza di Signal (che richiede il numero di telefono) e Matrix (che usa indirizzi utente @user:server), SimpleX Chat è la prima piattaforma di messaggistica decentralizzata che elimina totalmente qualsiasi identificatore utente globale o persistente.

Come funziona il protocollo SimpleX:

  • Code unidirezionali effimere (Simplex Queues): per ogni contatto o gruppo vengono create due code di trasmissione separate e isolate su server relay scelti dagli utenti.
  • Zero metadati centralizzati: i server di inoltro conoscono solo l'ID di una singola coda di ricezione o trasmissione temporanea, senza sapere chi sia l'altro capo della comunicazione né poter correlare contatti differenti dello stesso utente.
  • Crittografia a doppio strato (E2EE): i messaggi sono cifrati end-to-end con chiavi effimere e incapsulati in modo tale che nemmeno i server relay possano tracciare il grafo sociale degli utenti.
