Come si automatizza la configurazione di Cloudflare?

Approccio GitOps: la configurazione vive in un repository e GitHub Actions la applica. I tool:

  • zonecontrol — automatizza le impostazioni delle zone Cloudflare
  • wafcontrol — automatizza le impostazioni WAF Cloudflare
  • cf-box — toolkit Python per lavorare con le API su più account Cloudflare
  • dnscontrol-actions — aggiornamenti e rollback DNS multi-provider con DNSControl

Vantaggi: ogni modifica è una pull request, con review, storia e rollback.
