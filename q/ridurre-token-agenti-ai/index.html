Come si riduce il consumo di token di un agente AI?

Gli agenti di coding bruciano token leggendo output di comandi pieni di rumore: log di build, stack trace ripetuti, progress bar. l0-compressor è un proxy CLI in Rust che filtra, tronca e comprime l'output prima che l'agente lo legga: prefiggi qualsiasi comando con l0-compressor (o attivi l'hook trasparente per Claude Code / Gemini CLI) e il consumo scende del 50–80% su sessioni tipiche e dell'88–97% sugli output rumorosi – misurato col tokenizer, benchmarks pubblici nel repo.

Il punto ingegneristico: invece di mantenere un parser per ogni tool, usa filtri generici format-aware, preservando exit code, code degli errori e ordine dell'output. macOS e Linux (Windows sperimentale); documentazione.
