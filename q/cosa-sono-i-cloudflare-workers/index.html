Cosa sono i Cloudflare Workers?

I Workers sono codice JavaScript/TypeScript (o Wasm) che gira sui server edge di Cloudflare, in tutto il mondo, senza che tu gestisca nulla. Niente container né cold start da secondi: usano V8 isolates, partono in millisecondi ovunque.

Usi tipici: riscrivere richieste e risposte al volo, A/B testing, API leggere, autenticazione all'edge, gluing tra servizi. Intorno c'è un ecosistema intero – KV e R2 per lo storage, D1 (SQLite), Queues, cron trigger – che per molti progetti sostituisce un backend tradizionale, col CLI wrangler per lo sviluppo.

Il rovescio: è la forma più profonda di lock-in su Cloudflare – il codice è portabile a fatica, i dati vanno migrati. È una delle cose che flareover classifica onestamente come MANUAL: i Workers non hanno un equivalente self-hosted automatico.
