Come si conservano i log di Cloudflare a norma NIS2 e GDPR?

RainLogs risolve il dilemma tra conformità NIS2 (obbligo di conservazione evidenze di log) e GDPR (minimizzazione dati) aggregando e firmando crittograficamente i log di rete e di accesso prima di archiviarli su database distribuiti (Cloudflare D1 / S3 / SQLite locale).

Installazione e configurazione:
```bash
# 1. Setup con Node.js / Worker CLI
npm install -g @fabriziosalmi/rainlogs

# 2. Configurazione pipeline di ingestione e retention
rainlogs init --db d1 --retention-days 180 --anonymize-ip --sign-hmac
```

I dati sensibili vengono anonimizzati a livello di subnet prima della scrittura, e ogni blocco di log riceve un digest crittografico immutabile per garantire che nessun log possa essere manomesso post-incidente.
