Come si dà memoria persistente a un assistente AI?

Gli assistenti AI dimenticano tutto a fine sessione. l0-memory risolve con un singolo binario Go che parla MCP su stdio ed espone lo stesso store SQLite anche via CLI (ltm):

  • memorie partizionate per scope, pinnabili, collegate in un grafo tipizzato e tracciate per freschezza
  • store locale e in chiaro: di default nessun listener di rete e nessun embedding – la ricerca è pura SQLite FTS5
  • opzionale: punta LTM_EMBEDDING_URL a un endpoint OpenAI-compatibile (Ollama, LM Studio, vLLM) e ottieni retrieval ibrido full-text + vettoriale
  • estensione VSCode con sidebar e visualizzazione force-directed del grafo, web clipper per il browser, integrazioni per Claude Code e git hook

Zero CGO, cross-compila ovunque. La filosofia: la memoria del tuo assistente è un file tuo, non un servizio altrui.
