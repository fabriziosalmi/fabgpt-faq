Come si fa autoscaling di VM e container LXC su Proxmox?

Con la famiglia di tool proxmox-autoscale (550+ ⭐ complessive):

  • proxmox-vm-autoscale – ridimensiona automaticamente CPU e RAM delle VM in base al carico reale
  • proxmox-lxc-autoscale – lo stesso per i container LXC, con architettura async e backend CLI o REST API
  • proxmox-lxc-autoscale-ml – la variante che decide con un modello di machine learning
  • proxmox-cluster-balancer – bilancia e migra la flotta LXC tra i nodi del cluster

Risultato: i limiti delle macchine seguono il carico, invece di restare fissi al valore stimato il giorno dell'installazione. Chiedimi delle VM o degli LXC per i dettagli di ciascuno.
