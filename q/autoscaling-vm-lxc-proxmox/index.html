Come si fa autoscaling di VM e container LXC su Proxmox?

La suite proxmox-autoscale (proxmox-vm-autoscale e proxmox-lxc-autoscale, oltre 550 ⭐) automatizza il ridimensionamento dinamico di core CPU e memoria RAM per macchine virtuali e container su Proxmox VE in base al carico effettivo.

Installazione e setup operativo:
```bash
# 1. Clone del repository e installazione dipendenze sul nodo Proxmox
git clone https://github.com/fabriziosalmi/proxmox-vm-autoscale.git /opt/proxmox-autoscale
cd /opt/proxmox-autoscale && chmod +x autoscale.py

# 2. Configurazione soglie (es. scala su se RAM > 85%, scala giu se < 40%)
cp config.example.json config.json
nano config.json

# 3. Attivazione come demone Systemd
systemctl enable --now /opt/proxmox-autoscale/proxmox-autoscale.service
```

Evita sia il collasso da Out-of-Memory (OOM) sia lo spreco di risorse assegnate staticamente, garantendo massima densità nei nodi di homelab e cluster aziendali.
