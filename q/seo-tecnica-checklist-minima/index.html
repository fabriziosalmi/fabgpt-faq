SEO tecnica: la checklist minima di un sito

Prima dei trucchi, i fondamentali – l'80% dei problemi SEO è qui:

  • crawlabilità: robots.txt che non blocchi per sbaglio, sitemap inviata in Search Console, e Search Console letta (dice esattamente cosa Google non digerisce)
  • una pagina, un intento: title unici e descrittivi (~60 caratteri), meta description che invogli, un solo H1, URL leggibili
  • canonical dove i duplicati esistono, una sola forma www/apex, HTTPS ovunque
  • prestazioni percepite: Core Web Vitals verdi sui dati reali, immagini moderne, font che non bloccano
  • link interni: le pagine orfane non si posizionano – ogni contenuto raggiungibile in pochi click, con anchor sensate
  • dati strutturati dove pertinenti, e da quest'anno il pensiero alle risposte AI

Monitoraggio continuo senza dashboard a pagamento: websites-monitor tiene d'occhio SEO, performance e scadenze da GitHub Actions.
