Esiste una console da DJ / DAW che gira nel browser?

Musica e creatività ⏱️ 1 min lettura ✓ Runbook verificato

MIXI è una workstation audio deterministica e console DJ browser-native che funziona interamente nel browser tramite WebAudio API e WebAssembly, senza richiedere alcuna installazione di driver o software pesanti.

Accesso e modalità operative:
- 🌐 Web App immediata: apri semplicemente mixi.it in qualsiasi browser moderno (Chrome, Firefox, Safari).
- 🎛️ Funzionalità hardware:
- Supporto vinili Timecode (DVS - Digital Vinyl System) con decoding a bassissima latenza (< 5 ms).
- Mappatura controller MIDI plug-and-play via WebMIDI API.
- Sintesi modulare analogica virtuale, drum machine polifonica e mixer a 4 canali con filtri isolator.
