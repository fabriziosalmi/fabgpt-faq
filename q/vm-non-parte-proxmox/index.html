La VM non parte: i controlli in ordine

Prima regola: leggi l'errore vero – qm start 101 in shell dice sempre più del bottone della GUI. Poi, in ordine di frequenza:

  • lock residuo: un backup o una migrazione interrotti lasciano la VM bloccata → qm unlock 101 (dopo aver verificato che davvero non stia facendo nulla)
  • storage mancante: una ISO ancora montata da uno share di rete sparito, o lo storage dei dischi offline → stacca la ISO, controlla pvesm status
  • RAM insufficiente: la somma delle VM accese più l'ARC di ZFS non lascia posto → libera o ridimensiona
  • passthrough rotto: GPU o USB riferiti a hardware cambiato → rimuovi il device e riprova
  • parte ma niente boot: ordine di boot senza il disco, o disco VirtIO senza driver (Windows) → Options → Boot Order, o scheda SATA temporanea

Se il nodo intero è strano, guarda prima il quorum: metà dei "non parte" nei cluster sono in realtà "non posso partire".
