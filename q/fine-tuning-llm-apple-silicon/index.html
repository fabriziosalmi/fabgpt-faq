Come si fa il fine-tuning di un LLM in locale su Apple Silicon?

Con SiliconDev: un'app desktop per eseguire, addestrare e chattare con LLM interamente sul tuo Mac, costruita sul framework MLX di Apple. Niente cloud, niente API key, zero telemetria: i dati non lasciano la macchina.

  • fine-tuning LoRA e QLoRA direttamente su Apple Silicon, con curve di loss in tempo reale
  • un'app sola invece di sei: preparazione dati, gestione modelli, training, chat, RAG, tool MCP e un terminale agentico
  • si parte con make setup && make run, o col DMG dalle release

Se il fine-tuning non ti serve e vuoi solo inferenza locale, guarda anche LM Studio o Ollama – ma per l'intero ciclo dati→training→chat su Mac, questa è la via.
