Come si configura uno Smart Host/Relay SMTP cifrato per instradare la posta in uscita qualora l'IP del server rientri in blacklist residenziali?

La maggior parte dei provider Internet (ISP) blocca la porta 25 in uscita sulle connessioni residenziali o assegna indirizzi IP presenti nelle liste DUL (Dial-up/Dynamic User List) dei principali filtri antispam, rendendo impossibile la consegna diretta di email ai destinatari.

Soluzione con Smart Host su Postfix:

1. Configurazione in /etc/postfix/main.cf:
relayhost = [smtp.provider-affidabile.com]:587
smtp_sasl_auth_enable = yes
smtp_sasl_password_maps = hash:/etc/postfix/sasl_passwd
smtp_tls_security_level = encrypt
2. Mappatura Credenziali: inserisci in /etc/postfix/sasl_passwd le credenziali del servizio di relay (es. Brevo, Mailgun, relay aziendale), imposta i permessi chmod 600 e compila con postmap.
3. Verifica: tutta la posta locale viene cifrata e instradata attraverso il relay autorizzato con SPF/DKIM valido.
