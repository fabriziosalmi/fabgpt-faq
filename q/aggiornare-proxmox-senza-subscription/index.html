Proxmox e self-hosting

Come si aggiorna Proxmox senza subscription?

Proxmox è libero: la subscription paga il supporto e l'accesso al repository enterprise (più testato), non il software. Senza subscription si usa il repository pve-no-subscription: stessi pacchetti, ciclo di rilascio leggermente più rapido.

La procedura pulita: disabilita il repo enterprise (che senza chiave fallisce), abilita pve-no-subscription – dalla web UI (Repositories) o creando il file in /etc/apt/sources.list.d/ – e aggiorna con apt update && apt dist-upgrade (mai apt upgrade semplice su Proxmox). Lo stesso vale per PBS con il suo repo no-subscription.

Il famoso popup "No valid subscription" è solo un promemoria, innocuo. Per un ambiente di produzione aziendale la subscription Community ha senso: repo più conservativo e si finanzia lo sviluppo di quello che stai usando gratis.
