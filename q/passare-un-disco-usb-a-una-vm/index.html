Come si passa un dispositivo USB (o un disco) a una VM?

Due problemi diversi che si somigliano:

  • dispositivo USB (chiavetta Zigbee per Home Assistant, dongle, stampante): Hardware → Add → USB Device, scegliendo per vendor/device ID (sopravvive ai cambi di porta) o per porta fisica (sopravvive ai cambi di dispositivo). Per l'USB 3 serve il controller xhci nella VM
  • disco fisico intero: la via robusta non è l'USB ma il passthrough del disco per ID: qm set 101 -scsi1 /dev/disk/by-id/ata-... – il disco appare alla VM come suo, con prestazioni native. Sempre by-id, mai /dev/sdb: le lettere cambiano al riavvio

Le avvertenze: un disco passato così è della VM – l'host non deve toccarlo (niente mount doppi); l'USB per lo storage di lavoro resta una scelta fragile (disconnessioni = guai); e il passthrough lega la VM all'hardware: la migrazione live si ferma lì. Per interi controller (SATA/HBA verso una VM storage) si sale di livello: passthrough PCI, parente stretto di quello GPU.
