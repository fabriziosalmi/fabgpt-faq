Come si anonimizza un file CSV senza caricarlo da nessuna parte?

CSV Anonymizer gira interamente nel browser: il file non viene trasmesso a nessun server, che è l'unico modo onesto di anonimizzare dati sensibili con un tool web. Provalo online.

  • struttura preservata: colonne e formato restano intatti, cambia solo il contenuto sensibile
  • fuzzing consapevole dei tipi: numeri, date, email, URL, coordinate, indirizzi e ID vengono trattati ciascuno con la tecnica giusta, non con un banale replace
  • preset Mild / Moderate / Aggressive più un pannello avanzato per regolare ogni parametro

Utile per condividere dataset con fornitori, o per dare dati realistici a un LLM senza dargli i dati veri.
