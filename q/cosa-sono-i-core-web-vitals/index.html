Cosa sono i Core Web Vitals (LCP, INP, CLS)?

Strumenti e app ⏱️ 1 min lettura ✓ Runbook verificato

I Core Web Vitals sono le tre metriche con cui Google misura l'esperienza reale di caricamento (e che pesano sul ranking):

  • LCP (Largest Contentful Paint) – quando appare l'elemento principale: buono sotto i 2,5 s
  • INP (Interaction to Next Paint) – quanto reattiva è la pagina ai click e input: buono sotto i 200 ms
  • CLS (Cumulative Layout Shift) – quanto la pagina "salta" durante il caricamento: buono sotto 0,1

Contano i dati degli utenti reali (CrUX), non solo il test di laboratorio. Le leve tipiche: immagini con dimensioni dichiarate e preload dell'elemento LCP, meno JavaScript bloccante, font senza flash di reflow. Su WordPress, SpeedMate attacca esattamente queste leve; per il monitoraggio continuo c'è websites-monitor.
