Cos'è Proxmox Backup Server e perché usarlo?

Proxmox Backup Server (PBS) è il compagno ufficiale di PVE per i backup di VM e container, e cambia categoria rispetto al vecchio vzdump su NFS:

  • backup incrementali con deduplicazione: dopo il primo, ogni backup trasferisce e archivia solo i blocchi cambiati – decine di backup occupano poco più di uno
  • verify programmati (i backup corrotti si scoprono prima di averne bisogno), pruning automatico con policy di retention, cifratura lato client
  • restore granulare: la VM intera o il singolo file

Setup tipico: una macchina dedicata anche modesta (o un container su un NAS), datastore su dischi propri, job notturni da PVE, e una sync remota verso un secondo PBS fuori sede per la regola 3-2-1. Con proxxx lo monitori dallo stesso cockpit di PVE.
