Cos'è Wildbox, la piattaforma di sicurezza open source?

Wildbox è una piattaforma di sicurezza, SIEM e SOAR open source e self-hosted progettata per correlare log di sistema, rilevare intrusioni e reagire automaticamente isolando minacce in tempo reale senza la complessità e il consumo di risorse dei SIEM tradizionali.

Deploy rapido con Docker Compose:
```bash
# 1. Download stack e avvio container
curl -fsSL https://raw.githubusercontent.com/fabriziosalmi/wildbox/main/docker-compose.yml -o docker-compose.yml
docker compose up -d

# 2. Accesso alla dashboard di sicurezza
open http://localhost:9000
```

Funzionalità operative:
- Ricezione log via Syslog / Fluentbit / Webhooks.
- Motore di correlazione euristico con regole Sigma e pattern MITRE ATT&CK.
- Playbook SOAR: blocco automatico IP su firewall nftables, isolamento container compromessi e notifica istantanea all'amministratore.
