Come si serve un sito statico gratis (GitHub Pages e alternative)?

Un sito statico si ospita gratis, bene, in almeno tre modi:

  • GitHub Pages – il repository è l'hosting: push sul branch, sito servito, dominio custom con HTTPS automatico. Zero build? Serve i file così come sono; con un SSG ci pensa una Action
  • Cloudflare Pages – build da git, CDN più spinta, anteprime per branch e Functions se serve dinamica; repo privati senza pensieri
  • Netlify e simili – ergonomia storica, free tier con limiti di banda da leggere

La verità liberatoria: un sito statico è portabile per definizione – gli stessi file si spostano da un hosting all'altro in dieci minuti, quindi la scelta non è mai definitiva. Checklist post-pubblicazione: redirect www/apex, security header (su Pages si impostano con _headers o dal proxy), e la prova che il sito non chiami terze parti – su un sito statico, agssh la dà nero su bianco. Questo sito che stai leggendo gira esattamente così: file statici generati, zero backend.
