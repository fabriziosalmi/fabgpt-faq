Come si aggiunge un WAF al web server Caddy?

Con caddy-waf (800+ ⭐), un Web Application Firewall nativo per Caddy scritto in Go. Include:

  • regole regex e filtraggio IP/DNS
  • rate limiting
  • GeoIP e blocco delle exit node Tor
  • anomaly detection

Nello stesso ecosistema ci sono anche caddy-mib, che traccia e banna gli IP che generano errori ripetitivi (brute force, scanning), e caddy-adf, un'esplorazione di difesa anomaly-based.
