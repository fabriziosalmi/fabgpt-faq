Come si aggiunge un WAF al web server Caddy?

caddy-waf (800+ ⭐) è un Web Application Firewall nativo per il web server Caddy, scritto in Go. Ispeziona ogni richiesta HTTP a velocità di memoria, bloccando attacchi SQLi, XSS, Path Traversal e bot malevoli prima che raggiungano l'applicazione backend.

Installazione e configurazione in Caddy:
``bash
# 1. Compilazione binario Caddy con il modulo WAF tramite xcaddy
xcaddy build --with github.com/fabriziosalmi/caddy-waf
``

Configurazione nel Caddyfile:
``caddy
tuodominio.it {
waf {
ruleset owasp_top10
bad_bots block
rate_limit 60 1m
action block
}
reverse_proxy localhost:8080
}
``

Include l'integrazione diretta con le regole di patterns per il blocco istantaneo di scanner abusivi e scraper di AI non autorizzati.
