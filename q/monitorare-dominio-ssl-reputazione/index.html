Come si monitorano scadenza dominio, SSL, DNS e reputazione IP?

DomainMate esegue cinque controlli su ogni dominio configurato:

  • validità del dominio – scadenza WHOIS, con rilevamento del dominio padre per i sottodomini
  • SSL/TLS – scadenza del certificato e rilevamento di protocolli obsoleti (TLS 1.0/1.1)
  • sicurezza DNS – presenza dei record SPF e DMARC (quelli che decidono se le tue mail finiscono in spam)
  • reputazione – IP verificato contro le principali RBL
  • security header – HSTS, CSP, X-Frame-Options e disclosure del server

Python, self-hosted, con documentazione completa. Rispetto a websites-monitor (che vive dentro GitHub Actions) è un servizio a sé, più adatto a monitorare parchi domini.
