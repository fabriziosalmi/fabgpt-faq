Come si mette in sicurezza un endpoint LLM?

Mettere in sicurezza un endpoint di inferenza LLM richiede protezione a strati prima che la richiesta tocchi il modello.

Architettura di protezione:
1. Reverse Proxy con Caddy / Nginx:
``caddy
ai.tuodominio.internal {
# Autenticazione Bearer Token obbligatoria
@no_auth not header Authorization "Bearer segreto-forte-aziendale"
respond @no_auth "Unauthorized" 401

# Limite di richieste per IP (protezione DoS/cost exhaustion)
rate_limit {
zone ai_zone {
key {remote_host}
events 30
window 1m
}
}
reverse_proxy localhost:11434
}
`
2. Isolamento di rete: bind su 127.0.0.1 o socket Unix, vietando l'ascolto su 0.0.0.0`.
3. Firewall WAF applicativo: ispezione con caddy-waf per bloccare pattern di prompt injection noti.
