Cos'è CertMate e come gestisce i certificati TLS/SSL?

CertMate (500+ ⭐) è la piattaforma self-hosted per la gestione automatica del ciclo di vita dei certificati TLS. Risolve il problema dei certificati dimenticati o scaduti tramite ACME DNS-01 e HTTP-01 challenge automatici con oltre 30 DNS provider (Cloudflare, AWS Route53, Hetzner, OVH).

Installazione e avvio immediato:
- 🐳 Docker / Docker Compose:
``bash
docker run -d --name certmate \
-p 8080:8080 \
-v certmate_data:/app/data \
-e CERTMATE_AUTO_RENEW=true \
ghcr.io/fabriziosalmi/certmate:latest
`
- 💻 Binario standalone (Linux/macOS):
`bash
curl -fsSL https://raw.githubusercontent.com/fabriziosalmi/certmate/main/install.sh | bash
certmate daemon --config /etc/certmate.yaml
``

Caratteristiche: dashboard web moderna, emissione certificati Wildcard senza esporre porte HTTP, webhooks per reload di Nginx/Caddy/HAProxy e notifiche Telegram/Slack prima della scadenza.
