Come si configura Jellyfin per gestire lo streaming multimediale domestico senza dipendere da account o server cloud esterni?

Jellyfin è il media server self-hosted open source privo di tracciamento e costi di licenza. Per riprodurre flussi video 4K/HEVC su client multipli, è fondamentale abilitare la transcodifica hardware (Intel QuickSync o NVIDIA NVENC).

Configurazione Docker con Intel QuickSync (/dev/dri):
``yaml
services:
jellyfin:
image: jellyfin/jellyfin:latest
container_name: jellyfin
user: 1000:1000
group_add:
- "44" # GID del gruppo video / render
devices:
- /dev/dri/renderD128:/dev/dri/renderD128
- /dev/dri/card0:/dev/dri/card0
volumes:
- ./config:/config
- /mnt/storage/media:/media
ports:
- 8096:8096
restart: unless-stopped
``

Nel pannello di Jellyfin:
Dashboard → Riproduzione → Accelerazione Hardware → Seleziona Intel QuickSync (QSV) e spunta i codec H.264, HEVC e AV1.
