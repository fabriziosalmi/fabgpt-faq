Quanto costa far girare FabGPT-FAQ?

FabGPT-FAQ ⏱️ 2 min lettura ✓ Runbook verificato

Zero euro al mese, ed è una scelta di architettura, non una promozione:

  • niente inferenza: le risposte sono pre-scritte, quindi zero GPU e zero API – il costo marginale di una domanda in più è un lookup in un file JSON già nel browser
  • niente backend: file statici serviti da un hosting gratuito qualsiasi – quasi 300 pagine pesano pochi megabyte
  • niente database, niente coda, niente container da patchare: la superficie d'attacco è quella di una cartella di HTML

Il confronto che fa impressione: un chatbot RAG equivalente paga retrieval + inferenza a ogni domanda – da decine a centinaia di euro al mese già con poco traffico, più il monitoraggio delle allucinazioni. Qui il costo è spostato dove rende: il tempo umano per scrivere risposte giuste, una volta, versionate in git.

L'unico esborso opzionale: il dominio (~10 €/anno). Tutto il resto – build, test, benchmark, deploy – gira in CI gratuita o sul tuo portatile.
