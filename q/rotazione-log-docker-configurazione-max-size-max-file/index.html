Come si configura la rotazione automatica dei file di log di Docker per prevenire la saturazione imprevista dello spazio su disco?

Per impostazione predefinita, il driver di logging standard di Docker (json-file) memorizza tutto lo standard output e standard error dei container senza alcun limite di dimensione: su container rumorosi, i file in /var/lib/docker/containers/ possono rapidamente riempire l'intero disco provocando crash di sistema.

Configurazione globale consigliata in /etc/docker/daemon.json:

``json
{
"log-driver": "json-file",
"log-opts": {
"max-size": "50m",
"max-file": "3"
}
}
``

Questa direttiva impone un tetto massimo di 50 MB per singolo file di log e conserva al massimo 3 file di rotazione (occupazione massima garantita di 150 MB per container). Riavvia il servizio con systemctl restart docker per applicare le policy.
