Cloudflare Pages, Workers o Functions: quale usare?

Tre nomi, meno confusione di quanto sembri:

  • Pages – hosting per siti statici con build da git: push, build automatica, CDN globale, gratis in abbondanza. Se il sito è file (un SSG, una SPA), è la risposta
  • Workers – codice sull'edge: API, logica, riscritture. Se non c'è "un sito" ma un servizio, è la risposta
  • Pages Functions – il ponte: dentro un progetto Pages, la cartella functions/ diventa Workers instradati per path – il form da processare o la piccola API accanto al sito statico, senza progetto separato

Nota di direzione: Cloudflare sta unificando tutto sotto Workers (che oggi servono anche asset statici), quindi la distinzione andrà sfumando. E il consiglio controcorrente di sempre: un sito statico è portabile per natura – GitHub Pages, un VPS con Caddy, qualsiasi cosa lo serve. La comodità di Pages è reale; il lock-in delle Functions anche.
