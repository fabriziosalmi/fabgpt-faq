Come si velocizza un sito WordPress?

Un WordPress lento di solito soffre di tre mali: pagine rigenerate a ogni visita, immagini pesanti, JavaScript che blocca il rendering. SpeedMate li affronta tutti e tre da un plugin unico, senza configurazione:

  • cache HTML statica full-page con purge intelligente agli aggiornamenti, regole .htaccess generate da sole, cache warming e frammenti dinamici per i pezzi personalizzati (WooCommerce incluso)
  • immagini: conversione WebP all'upload, lazy-loading, dimensioni automatiche
  • JavaScript: dalla Safe Mode pronta per la produzione alla Beast Mode, che rinvia l'esecuzione degli script fino alla prima interazione dell'utente
  • chicche da Core Web Vitals: rilevamento dell'elemento LCP con preload hint, defer del CSS critico
