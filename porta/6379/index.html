Porta 6379/tcp – Redis

Protocollo: TCP

La cache in-memory usata da mezzo web (sessioni, code, cache di Nextcloud incluse).

Nota di sicurezza

Nasce senza autenticazione: un Redis esposto è compromesso in ore (cron malevoli via CONFIG SET). Bind su localhost/rete interna, requirepass o ACL, protected-mode attivo.

Verifica al volo

È in ascolto sul tuo server?

ss -tlnp | grep :6379

È raggiungibile da fuori? (dal tuo client)

nc -zv tuo-host 6379
